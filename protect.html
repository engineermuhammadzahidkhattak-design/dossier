Password protect a PDF

Lock a PDF so it only opens with a password you set. Encryption happens locally — your password is never sent anywhere.

Drop a PDF here, or click to browse
One file at a time.
    About this encryption: Dossier uses the PDF standard security handler (RC4, 40-bit) — the same baseline encryption format supported by every major PDF reader. It will stop casual viewers from opening the file without the password, but it is not the strongest encryption available; for highly sensitive documents, pair it with another layer of protection like an encrypted archive or a document-management platform with modern AES-256 encryption.
